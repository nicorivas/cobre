# Grado y Especificaciones del Cobre

## Grados de cobre refinado

### Grade A (LME)
- Pureza mínima: 99.99% Cu
- Registrado como brand en la LME
- Es el grado entregable contra contratos LME
- ~200 brands registrados globalmente

### COMEX
- Entregable: cátodo Grade 1 (equivalente a Grade A)
- Forma: cátodos (placas), no wirerod
- Peso por lote: 25,000 lbs (~11.34 t)

### Off-grade
- Cobre que no cumple Grade A
- Típicamente: mayor contenido de impurezas (Sb, As, Bi, Pb)
- Se vende con descuento al precio LME
- Común en producción SxEw de menor calidad

## Especificaciones LME

Para ser aceptado como brand LME:
- Pureza ≥ 99.99% Cu+Ag
- Forma: cátodos de tamaño estándar
- Peso individual: 100-125 kg por cátodo
- Impurezas máximas definidas (Se, Te, Pb, etc.)
- Proceso de listing: solicitud, muestras, aprobación

## Impacto en premiums

- Grade A de brand reconocido (e.g., Aurubis, Codelco): premium mínimo o estándar
- Grade A de brand menos conocido: posible descuento
- Off-grade: descuento de $50-200/t dependiendo de impurezas
- SxEw cathode: generalmente aceptado como Grade A si cumple specs

## Formas comerciales

| Forma | Descripción | Uso principal |
|---|---|---|
| Cátodo | Placa refinada 99.99% | Deliverable en bolsa, input para semis |
| Wirerod | Alambrón 8mm | Fabricación de cables (~75% consumo) |
| Billet/cake | Formas intermedias | Fabricación de tubos, láminas |
| Blister | ~99% Cu, sin refinar | Input para refinería electrolítica |
| Ánodo | ~99.5% Cu | Input para refinería electrolítica |
| Concentrado | ~25-35% Cu | Input para fundición |
